## 学习路径

```
战略层: 经营决策(经) → 营销增长(营)
制度层: 管理流程(管)
执行层: 运营效率(运) → 维护保障(维)
```

## 与My管理思维的融合

- **经营决策(经)**: 以目标结果为荣誉，科学量化导向
- **管理流程(管)**: 制度要严格，管理要均衡，执行要结果
- **运营效率(运)**: 工作要量化，今日事今日毕
- **维护保障(维)**: 以职责使命为保障，三颗心工作态度
- **营销增长(营)**: 以认知信任为极致，客户为中心的全链路闭环
