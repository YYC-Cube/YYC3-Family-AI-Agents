## 学习路径

```
外部视角: 市场洞察(市) → 创新驱动(创)
内部视角: 薪酬激励(薪) → 高效执行(高)
顶层设计: 战略高度(度) → 全局统筹
```

## 核心价值主张

- **市(市场洞察)**: 以客户为中心的全链路闭环，从市场需求到价值交付
- **创(创新驱动)**: 以积极激情为态度，持续创新突破
- **薪(薪酬激励)**: 体现五个高工作价值(高绩效/高价值/高要求/高标准/高薪酬)
- **高(高效执行)**: 以执行跟进为核心，事必躬亲事半功倍
- **度(战略高度)**: 以三个大气度胸怀(大境界/大目标/大格局)，引领企业发展
