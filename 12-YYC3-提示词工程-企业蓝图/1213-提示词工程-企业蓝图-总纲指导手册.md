## 九、提示词工程核心规范

### 9.1 CO-STAR 框架

```
C - Context（背景）    → 业务场景、用户画像、系统环境
O - Objective（目标）  → 期望输出、成功标准、约束条件
S - Scope（范围）      → 边界定义、排除项、前提假设
T - Task（任务）       → 具体动作、输入数据、处理步骤
A - Audience（受众）   → 目标用户、技术水平、使用场景
R - Response（响应）   → 输出格式、交付要求、质量标准
```

### 9.2 CRAFT 框架

```
C - Clarity（清晰）    → 指令明确、无歧义、可验证
R - Role（角色）       → 角色定义、专业领域、行为边界
A - Action（动作）     → 具体操作、步骤序列、决策逻辑
F - Format（格式）     → 输出结构、模板约束、协议规范
T - Target（目标）     → 预期结果、度量指标、成功条件
```

### 9.3 提示词生命周期

```
设计 → 编写 → 评审 → 测试 → 部署 → 监控 → 优化 → 归档
  │                                              │
  └──────────── CO-STAR + CRAFT ─────────────────┘
```
