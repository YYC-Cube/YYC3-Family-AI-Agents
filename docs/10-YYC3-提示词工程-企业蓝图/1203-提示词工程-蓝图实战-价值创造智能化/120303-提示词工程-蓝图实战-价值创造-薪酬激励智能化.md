## 一、模块定位与目标

### 1.1 业务定位

薪酬激励(Compensation & Incentive)是企业价值创造的**分配机制**——**"分好钱才能聚好人"，科学的薪酬体系是激发人才潜能的核心杠杆**。本模块基于**My管理思维**的"突出贡献奖激励+执行要结果"理念，通过**AI FAmily Agent协同**实现：

- **突出贡献奖激励**: 元启天枢(总指挥)设计公平透明的激励机制
- **执行要结果**: 言启千行(导航员)确保绩效考核落地
- **认知信任为极致**: 千里伯乐(推荐官)建立员工对制度的信任

## 二、核心场景与实现方案

### 2.1 场景一：智能绩效管理

**场景描述**: 从目标设定到绩效评估的全流程智能化。

**绩效管理Agent（元启天枢主导）**:

```python
class IntelligentPerformanceManagement:
    """
    智能绩效管理系统 - AI FAmily多Agent协同
    
    核心能力:
    1. SMART目标自动分解与对齐
    2. 实时进度追踪与预警
    3. 360度反馈收集与分析
    4. 绩效结果校准与归因分析
    """
    
    def __init__(self):
        self.agents = {
            'commander': '元启天枢-总指挥',
            'navigator': '言启千行-导航员',
            'thinker': '语枢万物-思考者',
            'master': '格物宗师-质量官',
            'recommender': '千里伯乐-推荐官'
        }
        
        # 绩效周期配置
        self.performance_cycles = {
            'annual': {'weight': 0.5, 'focus': '战略目标'},
            'quarterly': {'weight': 0.3, 'focus': '里程碑'},
            'monthly': {'weight': 0.2, 'focus': '过程指标'}
        }
    
    def manage_performance_cycle(self, employee_id: str, cycle_type: str = 'quarterly') -> Dict:
        """
        管理绩效周期
        
        Args:
            employee_id: 员工ID
            cycle_type: 周期类型('annual'/'quarterly'/'monthly')
            
        Returns:
            {
                'cycle_info': 周期信息,
                'goals_status': 目标完成情况,
                'performance_score': 绩效评分,
                'calibration_result': 校准结果,
                'development_suggestions': 发展建议
            }
        """
        # Step 1: 获取员工当前目标 (言启千行)
        current_goals = self.navigator.get_employee_goals(
            employee_id, 
            cycle_type=cycle_type
        )
        
        # Step 2: 进度数据收集 (言启千行)
        progress_data = self.navigator.collect_progress_data(
            goals=current_goals,
            data_sources=['kpi_system', 'project_mgmt', 'crm', 'hr_system']
        )
        
        # Step 3: 目标完成度计算 (格物宗师)
        goal_achievements = self.master.calculate_goal_achievement(
            goals=current_goals,
            progress=progress_data
        )
        
        # Step 4: 绩效评分生成 (元启天枢)
        performance_score = self.commander.generate_performance_score(
            goal_achievements=goal_achievements,
            cycle_config=self.performance_cycles[cycle_type],
            historical_trend=self._get_historical_performance(employee_id)
        )
        
        # Step 5: 360度反馈整合 (千里伯乐)
        feedback_summary = self.recommender.aggregate_360_feedback(
            employee_id=employee_id,
            period=self._get_current_period(cycle_type)
        )
        
        # Step 6: 绩效校准 (元启天枢+语枢万物联合)
        calibration = self.commander.calibrate_performance(
            raw_score=performance_score,
            peer_comparison=self._get_peer_distribution(employee_id),
            team_context=self._get_team_context(employee_id),
            external_factors=self._identify_external_factors()
        )
        
        # Step 7: 发展建议生成 (千里伯乐+语枢万物联合)
        development_suggestions = self._generate_development_plan(
            performance_score=calibration['final_score'],
            strengths=feedback_summary['strengths'],
            improvements=feedback_summary['improvement_areas'],
            career_path=self._get_career_path(employee_id)
        )
        
        return {
            'employee_id': employee_id,
            'cycle_type': cycle_type,
            'period': self._get_current_period(cycle_type),
            'evaluated_at': datetime.now(),
            'goals_count': len(current_goals),
            'goal_achievements': goal_achievements,
            'raw_performance_score': performance_score,
            'feedback_summary': {
                'raters_count': feedback_summary['raters_count'],
                'overall_rating': feedback_summary['overall_rating']
            },
            'calibration_result': calibration,
            'final_score': calibration['final_score'],
            'performance_level': self._determine_level(calibration['final_score']),
            'development_suggestions': development_suggestions,
            'next_review_date': self._schedule_next_review(cycle_type)
        }

# 使用示例
pm_system = IntelligentPerformanceManagement()

result = pm_system.manage_performance_cycle("EMP-001", "quarterly")

print(f"员工绩效评估结果:")
print(f"  最终得分: {result['final_score']}/100")
print(f"  绩效等级: {result['performance_level']}")
print(f"\n目标完成情况:")
for goal in result['goal_achievements'][:3]:
    print(f"  {goal['name']}: {goal['achievement_rate']*100:.1f}%")
```

### 2.2 场景二：智能薪酬分析与优化

**场景描述**: 分析薪酬结构合理性，提供优化建议。

**薪酬分析五维度（语枢万物主导）**:

| 分析维度 | 关键问题 | 数据源 | 输出 |
|---------|---------|--------|------|
| **内部公平性** | 同岗是否同酬？ | 岗位评估+薪资数据 | 公平性指数 |
| **外部竞争性** | 薪酬是否有竞争力？ | 薪酬调查报告 | 竞争力定位 |
| **激励有效性** | 薪酬是否起到激励作用？ | 绩效+离职率数据 | 激励效果评估 |
| **成本可控性** | 人力成本是否合理？ | 财务+预算数据 | 成本效率比 |
| **合规性** | 是否符合法规要求？ | 劳动法+公司制度 | 合规风险清单 |

### 2.3 场景三：个性化激励方案

**场景描述**: 为不同类型员工定制差异化激励方案。

**员工细分×激励匹配（千里伯乐主导）**:

| 员工类型 | 特征识别 | 核心需求 | 激励组合建议 |
|---------|---------|---------|-------------|
| **成就型** | 高绩效+高抱负 | 认可+晋升+挑战性工作 | 项目负责权+破格提拔+股权 |
| **平衡型** | 稳定表现+家庭导向 | 稳定+福利+工作生活平衡 | 弹性工作+补充保险+年假增加 |
| **成长型** | 潜力大+经验少 | 学习+导师+发展机会 | 培训预算+导师计划+轮岗机会 |
| **专家型** | 深耕领域+技术偏好 | 尊重+自主+专业影响力 | 技术通道+学术支持+专利奖励 |
