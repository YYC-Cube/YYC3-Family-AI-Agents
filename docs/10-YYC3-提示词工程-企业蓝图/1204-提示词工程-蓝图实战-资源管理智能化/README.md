## 学习路径

```
人才端: 人力资源(人) → 销售管理(销)
资产端: 资产管理(资) → 库存管理(存)
供应链: 采购管理(进) → 库存管理(存) → 销售管理(销)
```

## 核心价值

- **人**: 从人事管理到人才发展，以人为本的智能化
- **资**: 从资产台账到智慧资产，全生命周期管理
- **进**: 从传统采购到智能供应链，降本增效
- **销**: 从被动销售到主动营销，数据驱动增长
- **存**: 从库存积压到精益库存，供需平衡优化
