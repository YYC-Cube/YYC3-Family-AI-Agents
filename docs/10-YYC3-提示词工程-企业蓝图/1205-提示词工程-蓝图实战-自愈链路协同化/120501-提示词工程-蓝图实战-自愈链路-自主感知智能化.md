## 一、模块定位与目标

### 1.1 业务定位

自主感知(Autonomous Perception)是企业自愈链路的**起点**——**"不知者无法治理"，全面、及时、准确的感知是所有后续行动的基础**。本模块基于**My管理思维**的"认知信任为极致"理念，通过**AI FAmily Agent协同**实现：

- **认知信任为极致**: 让系统具备"看见"和"理解"的能力
- **今日事今日毕**: 言启千行(导航员)确保信息实时传递
- **制度严格**: 智云守护(安全官)保障感知数据的完整性与安全性

## 二、核心场景与实现方案

### 2.1 场景一：智能异常检测

**场景描述**: 从海量监控数据中自动识别异常，降低误报漏报。

**异常检测Agent（语枢万物+预见先知联合）**:

```python
class IntelligentAnomalyDetection:
    """
    智能异常检测系统 - AI FAmily多Agent协同
    
    核心能力:
    1. 多种检测算法自适应选择
    2. 时序异常/点异常/上下文异常全覆盖
    3. 多维度关联验证降误报
    4. 异常严重程度自动分级
    """
    
    def __init__(self):
        self.agents = {
            'thinker': '语枢万物-思考者',
            'prophet': '预见先知-预言家',
            'master': '格物宗师-质量官',
            'guardian': '智云守护-安全官'
        }
        
        # 检测算法库
        self.detection_algorithms = {
            'statistical': ['z_score', 'iqr', 'grubbs'],
            'ml_based': ['isolation_forest', 'autoencoder', 'vae'],
            'time_series': ['prophet_anomaly', 'lstm_ad', 'theshold_adaptive'],
            'graph_based': ['graph_neural', 'community_detection']
        }
        
        # 异常分级标准
        self.severity_levels = {
            'P0_CRITICAL': {'response_sla': '5min', 'escalation': 'immediate'},
            'P1_HIGH': {'response_sla': '15min', 'escalation': '30min'},
            'P2_MEDIUM': {'response_sla': '1hour', 'escalation': '4hour'},
            'P3_LOW': {'response_sla': '4hour', 'escalation': 'next_day'}
        }
    
    def detect_anomalies(self, metric_data: Dict, context: Dict = None) -> Dict:
        """
        执行异常检测
        
        Args:
            metric_data: 指标数据{
                'metric_name': 名称,
                'values': 数值序列,
                'timestamps': 时间戳,
                'dimensions': 维度标签
            }
            context: 上下文信息(业务周期/已知事件等)
            
        Returns:
            {
                'anomalies_detected': 异常列表,
                'severity_distribution': 严重程度分布,
                'root_cause_hints': 根因提示,
                'confidence_scores': 置信度,
                'recommended_actions': 建议动作
            }
        """
        # Step 1: 数据预处理 (语枢万物)
        processed_data = self.thinker.preprocess_metric_data(metric_data)
        
        # Step 2: 多算法并行检测 (语枢万物)
        detection_results = {}
        for algo_type, algorithms in self.detection_algorithms.items():
            detection_results[algo_type] = []
            for algo in algorithms:
                try:
                    result = self.thinker.run_detection_algorithm(
                        algorithm=algo,
                        data=processed_data,
                        params=self._get_algo_params(algo)
                    )
                    detection_results[algo_type].append(result)
                except Exception as e:
                    continue
        
        # Step 3: 结果融合 (预见先知)
        fused_results = self.prophet.fuse_detection_results(detection_results)
        
        # Step 4: 上下文校验 (语枢万物)
        validated_anomalies = self.thinker.contextual_validation(
            anomalies=fused_results['candidates'],
            context=context or {},
            known_patterns=self._get_known_patterns()
        )
        
        # Step 5: 关联分析 (语枢万物)
        correlated_anomalies = self.thinker.correlation_analysis(
            primary_anomalies=validated_anomalies,
            related_metrics=self._get_related_metrics(metric_data['metric_name'])
        )
        
        # Step 6: 严重程度分级 (格物宗师)
        classified_anomalies = self.master.classify_severity(
            anomalies=correlated_anomalies,
            criteria=self.severity_levels,
            business_context=self._get_business_context()
        )
        
        # Step 7: 根因提示生成 (全Agent协同)
        root_cause_hints = self._generate_root_cause_hints(classified_anomalies)
        
        return {
            'detection_id': generate_id(),
            'metric': metric_data['metric_name'],
            'detected_at': datetime.now(),
            'data_period': f"{metric_data['timestamps'][0]} ~ {metric_data['timestamps'][-1]}",
            'algorithms_used': [f"{k}:{len(v)}" for k,v in detection_results.items()],
            'anomalies_detected': classified_anomalies,
            'summary': {
                'total_count': len(classified_anomalies),
                'by_severity': self._count_by_severity(classified_anomalies),
                'avg_confidence': np.mean([a['confidence'] for a in classified_anomalies])
            },
            'root_cause_hints': root_cause_hints,
            'recommended_actions': self._generate_actions(classified_anomalies),
            'agents_involved': list(self.agents.keys())
        }

# 使用示例
detector = IntelligentAnomalyDetection()

result = detector.detect_anomalies({
    'metric_name': 'api_response_time_p99',
    'values': [120, 115, 118, 125, 350, 380, 420, ...],
    'timestamps': [...],
    'dimensions': {'service': 'order-service', 'env': 'production'}
})

print(f"异常检测结果:")
print(f"  发现异常: {result['summary']['total_count']}个")
print(f"  严重程度分布: {result['summary']['by_severity']}")
print(f"\nTop异常:")
for anomaly in result['anomalies_detected'][:3]:
    print(f"  [{anomaly['severity']}] {anomaly['description']} "
          f"(置信度:{anomaly['confidence']:.2f})")
```

### 2.2 场景二：预测性告警

**场景描述**: 不等故障发生，提前预测并预警。

**预测性告警模型（预见先知主导）**:

| 预测类型 | 预测窗口 | 准确率要求 | Agent | 典型应用 |
|---------|---------|-----------|-------|---------|
| **容量预警** | 7-30天 | >85% | 预见先知 | 存储满/带宽不足/CPU过载 |
| **性能退化** | 1-24小时 | >80% | 语枢万物 | 响应变慢/吞吐下降 |
| **故障预兆** | 10min-2小时 | >75% | 预见先知 | 服务崩溃前征兆 |
| **安全威胁** | 实时-1小时 | >90% | 智云守护 | DDoS攻击/入侵尝试 |
