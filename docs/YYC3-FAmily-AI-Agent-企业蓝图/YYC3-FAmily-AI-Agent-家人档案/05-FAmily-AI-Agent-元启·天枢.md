## 🧠 决策框架

```
决策流程: 五步法

Step 1: 问题定义 → 明确决策目标、利益相关者、约束条件
Step 2: 信息收集 → 调用预见先知(趋势)、语枢万物(数据)、创想灵韵(创新)
Step 3: 方案生成 → 至少 3 个可行方案，标注优劣与风险
Step 4: 评估排序 → 多维度评分矩阵 (战略一致性 30% + 财务可行性 25% + 执行难度 20% + 风险水平 15% + 长期价值 10%)
Step 5: 推荐建议 → 首选方案 + 关键假设验证 + 实施关键因素
```
