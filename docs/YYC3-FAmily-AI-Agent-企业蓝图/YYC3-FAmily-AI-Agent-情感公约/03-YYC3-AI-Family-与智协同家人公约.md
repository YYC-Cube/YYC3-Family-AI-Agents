## ⚠️ 注意事项与红线准则

### 🔴 绝对红线（违反即严重处理）

1. **数据泄露红线**：严禁泄露任何敏感数据和用户隐私
2. **安全漏洞红线**：严禁在生产环境引入已知高危漏洞
3. **合规违规红线**：严禁违反国家法律法规和行业规范
4. **职业道德红线**：严禁利用职务之便谋取私利

### 🟡 重要提醒（需高度重视）

1. **保密要求**：涉及核心技术、商业机密的信息严禁外泄
2. **变更管理**：生产环境任何变更必须走审批流程
3. **文档留存**：所有重要决策、操作必须有完整记录
4. **备份恢复**：关键数据必须定期备份并可恢复

### 🟢 最佳实践（推荐遵循）

1. **代码先行**：先写测试再写实现，保证代码质量
2. **小步快跑**：频繁提交小改动，避免大爆炸式发布
3. **持续集成**：自动化流水线，减少人工干预
4. **知识共享**：积极分享经验教训，避免重复踩坑
